# Testing Plan

## 1. Data Generation Testing

- Verify the Python IoT simulator generates valid sensor records.
- Check temperature, humidity, vibration, battery, location, and timestamp values.
- Confirm different commodities follow their configured environmental ranges.

## 2. Kafka Testing

- Verify the Kafka producer publishes sensor events successfully.
- Confirm messages are received by the Kafka consumer.
- Validate the JSON message structure and required fields.

## 3. Snowflake Testing

- Verify sensor records are inserted into the RAW layer.
- Check record counts and sample records.
- Validate data types and required fields.

## 4. dbt Testing

- Verify staging and mart models execute successfully.
- Check model relationships and transformations.
- Validate key analytical fields such as risk level and temperature conditions.

## 5. Dashboard Testing

- Verify Superset dashboards load correctly.
- Check KPI values against Snowflake data.
- Validate filters, charts, and recent sensor readings.

## 6. End-to-End Testing

The complete pipeline should be validated as:

```text
IoT Simulator
      ↓
Kafka
      ↓
Snowflake
      ↓
dbt
      ↓
Superset
````

The objective is to ensure that sensor data generated by the simulator reaches the dashboard correctly and produces consistent analytical results.
