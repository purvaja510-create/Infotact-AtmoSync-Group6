## 2. Temperature Monitoring

The dashboard provides temperature analysis through:

- Temperature trend by category
- Temperature alerts by container
- Recent sensor temperature readings

These views help identify temperature variations and containers experiencing temperature-related exceptions.

---

## 3. Shipment Risk Analysis

Shipment distribution is analyzed using the following risk levels:

- Critical
- High
- Medium
- Low

The dashboard provides shipment distribution by risk level to support prioritization of potentially problematic shipments.

---

## 4. Commodity and Category Analysis

The dashboard provides:

- Commodity distribution
- Shipment category distribution
- Top commodities by shipment volume

These views help compare shipment composition and identify frequently transported commodities.

---

## 5. Container Monitoring

Container-level analysis includes:

- Container activity
- Temperature alerts by container
- Recent sensor readings

The recent sensor readings table includes:

- Timestamp
- Container ID
- Commodity
- Category
- Temperature
- Humidity
- Battery level
- Source
- Destination
- Risk level

---

## 6. Dashboard Filters

The dashboard provides interactive filters for:

- Risk Level
- Commodity
- Destination
- Container
- Category

These filters allow users to focus the analysis on specific shipments, containers, commodities, destinations, or risk levels.
